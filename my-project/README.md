# 校园机会站 · 新生导航

一个面向在校学生、重点服务新生的校园活动与机会类小产品。纯前端实现，打开 `index.html` 即可运行，无需安装依赖或后端服务。

## 功能

- 使用题目提供的 22 条模拟校园信息，按学校/学院/学生自主发布等来源展示
- 首页推荐、全部活动、机会日历、我的收藏/报名
- 关键词搜索、来源筛选、类型筛选、时间筛选
- 活动详情：时间、地点、名额、报名截止、参与建议
- 收藏、报名/取消报名，数据持久化在浏览器 localStorage
- 发布活动表单，发布内容自动归类为“学生自主发布”
- 响应式设计，适配手机与电脑

## 运行

直接双击 `index.html`，或在 `my-project` 目录执行：

```bash
python3 -m http.server 5173
```

然后访问 <http://localhost:5173>。
